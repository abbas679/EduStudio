# JobTrack Pro

A React app to track job applications with status, search, and persistence.

## Features

- Add, delete, and update job applications
- Filter by status (Applied, Interview, Rejected)
- Search by job title or company
- Data persists using localStorage

## Tech Stack

- React, Hooks, JavaScript
- Custom hooks for job management
- LocalStorage for persistence

## How to run

1. `npm install`
2. `npm run dev`
3. Open http://localhost:5173
